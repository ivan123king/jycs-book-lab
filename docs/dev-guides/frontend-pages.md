# 页面模块开发指南

本文指导页面、组件和交互开发。页面开发要服务阅读和拆解闭环，不做营销页或复杂仪表盘。

## 页面总览

第一阶段页面模块包括：

1. 书库页
2. 书库内导入面板
3. 阅读页
4. 拆解工作台
5. 拆解方案设置页
6. 素材库页
7. 基础分析页

## 书库页

职责：

1. 展示已导入书籍。
2. 支持设置书库目录和导入书籍。
3. 支持打开最近阅读位置。
4. 展示小说名、小说大小和小说目录。

不要在书库页承载复杂分析。书库页只负责让用户找到书、导入书并进入工作流。

## 书库内导入面板

职责：

1. 选择本地小说文件。
2. 展示小说名和简介，并允许用户修改。
3. 展示原路径、文件大小和识别章节数。
4. 分页展示识别到的章节标题。
5. 确认后把小说复制到书库目录，并保存小说 JSON 和书库 `index.json`。

导入不是独立菜单，必须作为书库页右侧内容区的一种状态。导入时不编辑章节标题和正文，章节修改放在阅读页编辑模式。

## 阅读页

职责：

1. 展示章节目录。
2. 展示正文。
3. 支持阅读模式和编辑模式。
4. 支持选中文字。
5. 选中文字后显示浮动工具栏。
6. 触发创建拆解。

阅读页默认保持专注，不要默认铺满复杂表单。拆解工作台应在用户选文或主动打开时出现。

推荐布局：

```text
章节目录 | 正文
章节目录 | 正文 | 拆解工作台
```

## 拆解工作台

职责：

1. 接收当前选中的原文片段。
2. 根据本书拆解方案展示拆解类型和字段。
3. 保存拆解卡片。
4. 允许同一原文片段创建多个拆解。

拆解表单必须由当前书籍的拆解方案驱动，不能写死固定字段。

## 拆解方案设置页

职责：

1. 管理本书拆解维度。
2. 管理拆解类型。
3. 管理字段名称、类型、顺序、必填、显示状态。
4. 支持从模板创建方案。
5. 支持将当前方案另存为模板。

第一阶段只做必要配置能力，先避免复杂权限、版本、多用户协作。

## 素材库页

职责：

1. 展示所有拆解沉淀出的素材。
2. 支持搜索。
3. 支持分类筛选。
4. 支持标签筛选。
5. 支持查看来源。
6. 支持编辑、删除、收藏。

素材卡片必须能回到来源书籍、章节和原文片段。

## 基础分析页

第一阶段只做轻量统计：

1. 按拆解类型统计数量。
2. 按标签统计数量。
3. 按章节展示拆解分布。

复杂剧情结构、人物关系图、跨书比较属于后续阶段。

## 交互原则

1. 常用操作少点击。
2. 选文后能快速创建拆解。
3. 表单字段随拆解方案变化。
4. 页面状态要清晰提示保存成功、保存失败、未保存修改。
5. 长文本阅读区域不要被工具栏遮挡。
6. 编辑正文前要明确当前处于编辑模式。
