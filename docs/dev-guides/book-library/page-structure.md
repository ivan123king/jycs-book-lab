# 书库页面结构

本文定义书库页和书库内导入面板的页面结构，用于指导后续 Vue 3 + Naive UI 编码。

## 书库页

职责：

1. 展示当前书库目录。
2. 支持设置或更换书库目录。
3. 读取 `index.json` 展示小说列表。
4. 展示小说名、小说目录、小说大小。
5. 支持打开小说、在右侧内容区进入导入状态、定位异常路径。

推荐结构：

```text
顶部操作区：书库目录 / 更换目录 / 导入小说
筛选区：搜索小说名
列表区：小说名 / 小说大小 / 小说目录 / 打开
状态区：空书库、路径异常、读取失败
```

边界：

1. 不展示章节详情。
2. 不展示拆解和素材详情。
3. 不直接编辑单本小说数据。

## 书库内导入面板

导入不是独立菜单。用户点击左侧“书库”后，在书库右侧内容区点击“导入小说”，进入导入面板。

推荐结构：

```text
小说信息区：小说名 / 简介
导入信息区：原路径 / 小说大小 / 识别章节数
章节信息区：分页章节标题表
底部操作区：取消 / 重新识别 / 确认导入
```

章节列表必须分页。一本小说可能有几千章，不允许设计成逐章确认，也不在导入时编辑章节标题或正文。

## 导入流程

1. 用户选择 TXT 小说文件。
2. 系统读取文件并识别章节。
3. 系统预生成入库目录和小说名。
4. 页面展示小说名、简介、原路径、大小、章节数和分页章节标题。
5. 用户可修改小说名和简介。
6. 用户点击确认导入。
7. 后端复制小说到书库小说目录。
8. 后端写入该小说目录下的 `book.json`。
9. 后端更新书库根目录 `index.json`。
10. 后续章节标题和正文修改在阅读工作台编辑 TAB 完成。

## 页面状态

页面至少要有以下状态：

1. 未选择文件。
2. 正在读取文件。
3. 章节识别完成。
4. 正在确认导入。
5. 导入成功。
6. 导入失败，可重新选择文件或重试。
