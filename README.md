# 指南
这是一个用来拆书的工具，包含拆小说剧情和写作手法，用来形成自己的素材库，供以后编写小说时参考。

# 路径说明
docs/dev-guides/windows-packaging.md  这里面是windows打包文档，用来指导如何打windows下的软件，包含exe和zip文件
docs/dev-guides/project-initialization.md  这里面包含了如何创建的工程，以及使用wails dev启动工程; 启动工程运行此命令需要在init目录下，那下面才有wails.json文件

# 软件界面概览
## 书库
  书库是用来导入要分析的小说的，目前支持txt文档。拆解的小说可以形成素材存放到书库素材，这是全局通用的，不会因为把小说移除就看不到书库素材
