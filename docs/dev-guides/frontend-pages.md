# 页面模块开发指南

本文指导页面、组件和交互开发。页面开发要服务阅读和拆解闭环，不做营销页或复杂仪表盘。

## 页面总览

第一阶段页面模块包括：

1. 书库页
2. 书库内导入面板
3. 阅读工作台
4. 写作手法拆解卡片页
5. 拆解方案设置页
6. 剧情拆解页
7. 小说内素材库页
8. 书库素材库页
9. 基础分析页

## 书库页

职责：

1. 展示已导入书籍。
2. 支持设置书库目录和导入书籍。
3. 支持打开最近阅读位置。
4. 展示小说名、小说大小、小说目录和阅读进度百分比。

不要在书库页承载复杂分析。书库页只负责让用户找到书、导入书并进入工作流。

## 书库内导入面板

职责：

1. 选择本地小说文件。
2. 展示小说名和简介，并允许用户修改。
3. 展示原路径、文件大小和识别章节数。
4. 分页展示识别到的章节标题。
5. 确认后把小说复制到书库目录，并保存小说 JSON 和书库 `index.json`。

导入不是独立菜单，必须作为书库页右侧内容区的一种状态。导入时不编辑章节标题和正文，章节修改放在阅读工作台编辑 TAB。

## 阅读工作台

职责：

1. 默认恢复当前书上次阅读位置。
2. 当应用重启后尚未打开当前书时，点击阅读模块应从最近打开小说入口恢复上次阅读位置。
3. 展示阅读 / 编辑两个 TAB。
4. 在阅读 TAB 中展示整章正文，并通过滚动阅读保存当前位置。
5. 通过右侧目录按钮打开分页目录，目录默认定位到当前章节所在页。
6. 支持选中文字。
7. 选中文字后显示浮动工具栏。
8. 点击创建拆解后打开拆解弹框。
9. 在编辑 TAB 中修改当前章节标题和正文。
10. 支持当前书独立的正文字体大小设置，设置保存到该小说项目目录。
11. 阅读页顶部工具栏和底部章节切换栏固定，鼠标滚轮只滚动正文内容区。
12. 支持在目录列表中右键章节并拆分章节，用于修正自动识别错误的章节目录。
13. 支持在目录项旁打开章节小记弹框，保存本章自由小记。

阅读工作台默认保持专注，不要在顶部铺章节分页，不要常驻章节目录，不要在正文下方展开大型拆解表单。详细规则见 `docs/dev-guides/reading-workbench/`。

推荐布局：

```text
顶部：阅读 / 编辑 TAB、目录按钮、搜索
主体：整章滚动正文阅读区
底部：上一章 / 当前章节位置 / 下一章
弹层：分页章节目录，目录项右键可拆分章节
弹框：选文创建拆解
弹框：目录拆分章节
```

## 写作手法拆解工作台

职责：

1. 接收当前选中的原文片段。
2. 根据本书拆解方案展示拆解类型、维度和看法输入区。
3. 保存写作手法拆解卡片。
4. 允许同一原文片段创建多个拆解。

写作手法拆解工作台在阅读工作台内表现为“创建拆解弹框”，不作为正文下方常驻区域。弹框必须由当前书籍的写作手法模板驱动，展示类型、维度和用户看法输入区，不能写死固定类型或维度。

写作手法拆解卡片页负责集中管理当前书已有写作手法拆解卡片，支持按章节、拆解类型、标签、关键词和创建时间筛选，并支持从卡片沉淀为素材。详细规则见 `docs/dev-guides/writing-technique-deconstruction/implementation.md`。

## 拆解方案设置页

职责：

1. 管理本书拆解模板列表。
2. 管理模板名称。
3. 管理拆解类型。
4. 管理类型下的拆解维度。
5. 支持将模板设为当前方案。
6. 支持将当前内容另存为模板。

第一阶段只做必要配置能力，先避免复杂权限、版本、多用户协作。

## 剧情拆解页

职责：

1. 展示当前书已有剧情拆解卡片。
2. 支持按剧情名称、剧情类型、章节范围、标签和关键词筛选。
3. 提供“新建剧情拆解”按钮。
4. 新建时弹框顶部提供章节范围输入，必须支持 `1-3, 8, 12-15` 这类非连续范围。
5. 章节范围旁提供“章节内容”按钮，按需展示所选章节目录和正文，辅助用户回看内容。
6. 剧情名称下方提供剧情简介大输入框，支持 Tab 键中文首行缩进。
7. 根据当前书剧情模板加载剧情类型和初始维度。
8. 用户可以在本次剧情拆解中修改、新增、删除维度，模板只作为分析提示，不被自动改写。
9. 每个维度有独立输入框，支持单个维度折叠，并提供全部展开和全部收起。
10. 点击剧情拆解卡片时，以同一弹框查看和编辑详情，并保留章节内容查看入口。
11. 关闭弹框时如果有未保存修改，必须提示保存草稿、不保存并关闭或取消。
12. 支持从剧情拆解卡片沉淀为素材。

详细规则见 `docs/dev-guides/story-plot-deconstruction/implementation.md`。

## 小说内素材库页

职责：

1. 展示当前书中由写作手法拆解和剧情拆解沉淀出的素材。
2. 支持搜索。
3. 支持标签筛选。
4. 支持查看来源。
5. 支持编辑和删除。
6. 支持跳转到来源原文、写作手法拆解卡片或剧情拆解卡片。
7. 素材列表按创建时间排序，编辑后不因更新时间变化而跳到列表前面。
8. 素材详情重点展示标题、拆解类型、维度、原文、拆解说明和标签，不展示复杂分类表单。

小说内素材是当前小说项目目录中的正式数据，复制小说项目目录时必须跟随迁移。素材卡片必须能回到来源书籍、章节、原文片段或剧情章节范围。详细规则见 `docs/dev-guides/book-material-library/implementation.md`。

## 书库素材库页

职责：

1. 聚合展示当前书库中的单书素材引用和书库自有素材。
2. 支持按书籍、素材类型、标签和关键词筛选。
3. 支持分页查询，默认每页 50 条，避免上千条素材一次性渲染。
4. 支持查看标题、拆解类型、维度、原文、拆解说明和标签。
5. 支持手动新增书库自有素材。
6. 支持编辑和删除书库自有素材。
7. 支持打开来源小说项目；单书素材引用的删除和编辑回到小说内素材页处理。
8. 移除书籍前必须把该书已有素材迁移为书库自有素材，避免引用随单书目录删除而失效。

书库自有素材是书库目录中的正式数据，单书素材引用仍以单书项目目录为正式数据源。详细规则见 `docs/dev-guides/global-material-library.md`。

## 基础分析页

第一阶段只做轻量统计：

1. 按拆解类型统计数量。
2. 按标签统计数量。
3. 按章节展示写作手法拆解和剧情拆解分布。

复杂剧情结构图、人物关系图、跨书比较属于后续阶段。

## 交互原则

1. 常用操作少点击。
2. 选文后能快速创建拆解。
3. 类型和维度随拆解方案变化。
4. 页面状态要清晰提示保存成功、保存失败、未保存修改。
5. 长文本阅读区域不要被工具栏遮挡。
6. 编辑正文前要明确当前处于编辑模式。
