# 阅读工作台页面结构

本文定义阅读工作台的页面结构，用于指导后续 Vue 3 + Naive UI 编码。阅读工作台应是当前书工作区的默认入口，整体由阅读 TAB、编辑 TAB、目录弹层和拆解弹框组成。

## 页面入口

进入阅读工作台有两类入口：

1. 用户从书库点击某本小说。
2. 用户在已打开小说项目后点击当前书工作区的“阅读”菜单。
3. 用户重新运行软件后，直接点击“阅读”菜单。

这些入口都必须优先读取该小说项目目录中的阅读位置。如果没有当前书上下文，但应用设置中存在最近打开小说入口，应先打开最近小说，再恢复其阅读位置。如果没有阅读位置，则打开第一章第一处内容。

打开规则：

1. 读取当前小说 `book.json` 和阅读状态文件。
2. 如果当前书为空，从应用系统数据目录读取最近打开小说路径，该路径只作为入口，不保存阅读位置。
3. 定位到 `lastPosition.chapterId` 和对应正文位置。
4. 渲染阅读 TAB。
5. 顶部显示当前书名、当前章节摘要和阅读进度百分比。
6. 右侧目录按钮可随时打开目录弹层。

## 推荐布局

阅读工作台整体布局：

```text
顶部工作区：当前书名 / 阅读进度 / 阅读 TAB / 编辑 TAB / 目录按钮 / 搜索
阅读内容区：上一页操作区 | 正文内容区 | 下一页操作区
底部状态区：当前章节 / 页内位置 / 保存状态 / 选文反馈
```

关键要求：

1. 页面顶部不展示章节分页。
2. 页面左侧不常驻章节目录。
3. 阅读正文位于主区域，左右两侧是稳定的上一页和下一页操作区。
4. 目录入口放在右侧按钮中，可以是抽屉、弹出层或右侧浮层。
5. 拆解表单只在用户创建拆解时以弹框出现。

## 阅读 / 编辑 TAB

阅读工作台只有两个主 TAB：

```text
阅读 | 编辑
```

### 阅读 TAB

职责：

1. 展示当前阅读内容。
2. 支持上一页、下一页。
3. 支持打开目录弹层并跳转章节。
4. 支持文本选择。
5. 选中文字后显示浮动工具栏。
6. 点击“创建拆解”后打开拆解弹框。
7. 保存阅读位置。

阅读 TAB 不展示完整拆解表单，不展示素材库列表，不展示复杂章节表格。

### 编辑 TAB

职责：

1. 展示当前章节标题输入框。
2. 展示当前章节正文编辑区。
3. 支持保存章节标题和正文。
4. 支持放弃修改。
5. 保存后更新章节 TXT 和 `book.json` 中对应章节元数据。

编辑 TAB 不承担导入阶段的章节识别，也不直接编辑拆解方案。

## 阅读内容区

阅读内容区推荐结构：

```text
上一页按钮 | 当前阅读内容 | 下一页按钮
```

交互规则：

1. 左侧上一页按钮固定在阅读内容区左侧。
2. 右侧下一页按钮固定在阅读内容区右侧。
3. 中间正文区域负责展示当前页或当前章节片段。
4. 点击上一页或下一页后加载不同内容，并更新阅读位置。
5. 如果翻页跨章节，需要同步更新当前章节、阅读进度和目录定位。
6. 长文本内容不能被工具栏、弹框或底部状态遮挡。

第一阶段可以按章节内分页实现；后续如改成连续滚动，也必须保留明确的上一页 / 下一页阅读动作和可恢复阅读位置。

## 目录弹层

目录弹层由右侧目录按钮打开。

推荐结构：

```text
目录弹层
├── 当前书章节总数
├── 搜索章节标题
├── 分页章节列表
└── 上一目录页 / 下一目录页 / 页码
```

分页定位规则：

1. 目录每页展示固定数量章节，例如每页 30 或 50 章。
2. 打开目录时，根据当前章节顺序计算目录页。
3. 如果当前阅读到第 302 章，且目录每页 50 章，则默认打开第 7 页。
4. 用户可以在目录弹层内前后翻目录页。
5. 用户点击章节后，阅读内容区跳转到该章节最近位置或章节开头。
6. 目录弹层关闭后，阅读正文区域大小恢复，不保留空白占位。

目录只展示章节标题、序号、拆解数量和阅读进度等轻量信息，不展示正文全文。

## 选文与拆解弹框

选文流程：

1. 用户在阅读 TAB 中选中文字。
2. 页面记录选文所属 `bookId`、`chapterId`、开始位置、结束位置和选中文本。
3. 选文附近显示轻量浮动工具栏。
4. 用户点击“创建拆解”。
5. 页面打开拆解弹框。

拆解弹框结构：

```text
拆解弹框
├── 原文片段预览
├── 拆解类型选择
├── 当前类型对应字段表单
├── 标签和分类入口
└── 取消 / 保存 / 保存并继续创建
```

弹框规则：

1. 字段必须由当前书拆解方案动态渲染。
2. 弹框内必须展示原文片段，避免用户脱离上下文填写。
3. 保存后创建拆解卡片，并保留来源追溯。
4. “保存并继续创建”允许同一原文片段继续创建另一张拆解卡片。
5. 弹框关闭后返回阅读位置，不改变当前阅读内容。

## 页面状态

页面至少要处理以下状态：

1. 正在打开小说项目。
2. 未找到阅读位置，打开第一章。
3. 已恢复上次阅读位置。
4. 正在加载上一页或下一页。
5. 正在打开目录弹层。
6. 正在跳转章节。
7. 已选中文字。
8. 正在创建拆解。
9. 拆解保存成功。
10. 拆解保存失败，可重试。
11. 编辑内容未保存。
12. 章节保存成功。
13. 章节保存失败，可重试或放弃修改。

## 组件建议

第一阶段可以拆分以下组件：

| 组件 | 职责 |
| --- | --- |
| `ReadingWorkbenchPage` | 阅读工作台页面容器，负责当前书阅读状态和 TAB 切换。 |
| `ReaderTabs` | 阅读 / 编辑 TAB。 |
| `ReaderPager` | 左右上一页、下一页操作区和翻页状态。 |
| `ReaderContent` | 展示正文并处理文本选择。 |
| `ChapterCatalogButton` | 右侧目录入口按钮。 |
| `ChapterCatalogOverlay` | 分页展示章节目录并支持跳转。 |
| `SelectionToolbar` | 选文后的浮动工具栏。 |
| `DeconstructionDialog` | 创建拆解弹框。 |
| `PlanDrivenForm` | 根据当前书拆解方案动态渲染字段。 |
| `ChapterEditor` | 编辑章节标题和正文。 |

页面组件只管理交互状态，读取、保存、章节定位和拆解持久化应通过本地数据服务或 Wails 后端 API 完成。
