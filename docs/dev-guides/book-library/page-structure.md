# 书库页面结构

本文定义书库页和书库内导入面板的页面结构，用于指导后续 Vue 3 + Naive UI 编码。

## 书库页

职责：

1. 展示当前书库目录。
2. 支持设置或更换书库目录。
3. 读取 `index.json` 展示小说列表。
4. 展示小说名、小说目录、小说大小和阅读进度百分比。
5. 支持打开小说、移除小说、在右侧内容区进入导入状态、定位异常路径。

推荐结构：

```text
顶部操作区：书库目录 / 更换目录 / 导入小说
筛选区：搜索小说名
列表区：小说名 / 小说大小 / 阅读进度百分比 / 小说目录 / 移除 / 打开
状态区：空书库、路径异常、读取失败
```

边界：

1. 不展示章节详情。
2. 不展示拆解和素材详情。
3. 不直接编辑单本小说数据。
4. 移除操作必须有二次确认，并清楚提示会删除该书在书库中的项目目录。
5. 移除成功后必须刷新书库列表；如果移除的是当前打开书籍，需要清空当前书上下文，避免继续访问已删除目录。
6. 阅读进度百分比来自单书项目目录中的阅读状态摘要；读取失败时可显示 0%，但不能因此覆盖单书正式数据。

## 移除流程

1. 用户在书卡中点击“移除”。
2. 页面展示确认提示，说明会删除该书在书库中的项目目录。
3. 用户确认后，前端调用后端书库移除 API。
4. 后端校验目标目录位于当前书库 `books/` 子目录下。
5. 后端删除该书项目目录，并从 `index.json` 移除对应条目。
6. 前端使用后端返回的最新书库状态刷新列表。

## 书库内导入面板

导入不是独立菜单。用户点击左侧“书库”后，在书库右侧内容区点击“导入小说”，进入导入面板。

推荐结构：

```text
小说信息区：小说名 / 简介
导入信息区：原路径 / 小说大小 / 识别章节数
章节信息区：分页章节标题表
底部操作区：取消 / 重新识别 / 确认导入
```

章节列表必须分页。一本小说可能有几千章，不允许设计成逐章确认，也不在导入时编辑章节标题或正文。

## 导入流程

1. 用户选择 TXT 小说文件。
2. 系统读取文件并识别章节。
3. 系统预生成入库目录和小说名。
4. 页面展示小说名、简介、原路径、大小、章节数和分页章节标题。
5. 用户可修改小说名和简介。
6. 用户点击确认导入。
7. 后端复制小说到书库小说目录。
8. 后端写入该小说目录下的 `book.json`。
9. 后端更新书库根目录 `index.json`。
10. 后续章节标题和正文修改在阅读工作台编辑 TAB 完成。

## 页面状态

页面至少要有以下状态：

1. 未选择文件。
2. 正在读取文件。
3. 章节识别完成。
4. 正在确认导入。
5. 导入成功。
6. 导入失败，可重新选择文件或重试。
