# 页面整体结构与模块拆分

本文用于在正式编码前统一佳依拆书第一阶段的页面结构、导航层级和页面模块职责。它只描述页面设计与功能边界，不替代后端数据模型文档，也不提前扩张到跨书比较、复杂可视化或 AI 自动拆解。

## 设计目标

第一阶段页面应围绕一个核心闭环组织：

```text
导入小说 -> 阅读原文 -> 选中文字 -> 创建拆解 -> 沉淀素材 -> 形成个人写作知识库
```

页面结构需要同时满足两类使用状态：

1. 还没有打开小说项目：帮助用户找到、创建或导入一本书。
2. 已打开小说项目：围绕当前书完成阅读、拆解、素材沉淀和方案配置。

页面不要把产品做成普通阅读器或普通笔记软件。阅读是入口，拆解是核心动作，素材库是沉淀结果。

## 顶层页面结构

建议使用“全局壳层 + 当前书工作区”的结构：

```text
应用壳层
├── 书库
├── 当前书工作区
│   ├── 阅读与拆解
│   ├── 拆解卡片
│   ├── 素材库
│   ├── 拆解方案
│   └── 基础分析
└── 全局设置
```

### 应用壳层

职责：

1. 承载窗口级布局、主导航和当前项目状态。
2. 展示当前打开的小说项目名称、保存状态和最近操作反馈。
3. 负责在书库、当前书工作区和全局设置之间切换。

不负责：

1. 不直接处理小说正文、拆解卡片或素材的持久化。
2. 不承载复杂业务表单。
3. 不把某一本书的数据写入应用系统数据目录。

## 页面模块总览

第一阶段建议拆分为以下页面模块：

| 页面模块 | 入口位置 | 核心职责 | 第一阶段重点 |
| --- | --- | --- | --- |
| 书库页 | 应用启动默认页 | 管理书库目录和小说打开入口 | 快速打开已有书、导入新书 |
| 书库内导入面板 | 书库页右侧内容区 | 将 TXT 小说复制入书库并生成小说数据 | 编辑小说名和简介，分页查看章节标题 |
| 阅读工作台 | 当前书工作区默认页 | 阅读正文、编辑正文、选文创建拆解 | 恢复上次位置、阅读/编辑 TAB、选文弹框拆解 |
| 拆解卡片页 | 当前书工作区 | 管理本书已有拆解卡片 | 搜索、筛选、回到原文 |
| 素材库页 | 当前书工作区 | 管理从拆解沉淀出的素材 | 来源追溯、分类标签 |
| 拆解方案页 | 当前书工作区 | 配置当前书的拆解维度、类型和字段 | 字段不写死、按书独立 |
| 基础分析页 | 当前书工作区 | 展示轻量统计 | 只做数量和分布统计 |
| 全局设置页 | 应用壳层 | 管理应用级偏好 | 只保存与具体书无关的设置 |

## 推荐导航模型

### 未打开小说项目

未打开项目时，主界面只保留轻量入口：

```text
书库
├── 最近打开
├── 所有已记录项目
└── 导入小说
```

此状态下不显示拆解、素材、分析等当前书页面，避免用户误以为这些数据是全局混放的。

### 已打开小说项目

打开一本书后，进入当前书工作区：

```text
当前书
├── 阅读
├── 拆解
├── 素材
├── 方案
└── 分析
```

当前书工作区的所有业务页面都必须以当前小说项目目录为数据边界。切换书籍时，页面状态、筛选条件和草稿状态需要明确处理，不能混用上一本文档的上下文。

## 页面职责说明

### 书库页

职责：

1. 展示用户设置的书库目录。
2. 读取书库 `index.json`，展示小说名、小说目录和小说大小。
3. 支持设置书库目录、导入小说、打开小说。
4. 对路径不存在、无权限或数据损坏给出可恢复提示。

边界：

1. 不展示章节、拆解和素材详情。
2. 不修改单本小说的拆解方案。
3. 详细规则见 `docs/dev-guides/book-library/`。

### 书库内导入面板

职责：

1. 选择本地小说 TXT 文件。
2. 根据用户设置的书库目录生成单本小说目录。
3. 展示小说名、简介、原路径、文件大小和章节数。
4. 章节列表必须分页，只展示识别出的章节标题。
5. 支持用户修改小说名和简介。
6. 确认导入后复制小说文件，写入单本小说 `book.json`，并更新书库 `index.json`。
7. 导入失败时给出重试、重新选择文件等恢复动作。

边界：

1. 章节识别规则由后端或独立服务负责，页面只展示和提交用户修正结果。
2. 不要求用户逐章确认。
3. 不在导入流程中修改章节标题或正文。
4. 不在导入流程中要求用户完成复杂拆解方案配置。

### 阅读工作台

职责：

1. 默认打开当前书上次阅读位置。
2. 从书库点击小说时，进入该小说上次阅读到的位置。
3. 展示阅读和编辑两个 TAB。
4. 阅读 TAB 展示正文，并通过上一页、下一页加载不同阅读内容。
5. 编辑 TAB 修改当前章节标题和正文。
6. 通过右侧目录按钮打开分页目录。
7. 目录打开时默认展示当前章节所在目录页，例如当前为第 302 章时展示第 302 章所在页。
8. 支持用户选中文字。
9. 选中文字后展示浮动工具栏，提供创建拆解、复制、标记等入口。
10. 点击创建拆解后打开拆解弹框。
11. 根据当前书拆解方案渲染拆解表单。
12. 保存拆解卡片，并允许同一原文片段创建多个拆解。
13. 保存后可选择继续阅读、继续为同一片段创建拆解，或沉淀为素材。

推荐布局：

```text
顶部：当前书信息 / 阅读 TAB / 编辑 TAB / 目录按钮
主体：上一页 | 正文阅读区 | 下一页
弹层：分页章节目录
弹框：选文创建拆解
```

边界：

1. 正文阅读区始终是主区域，不被复杂面板压缩到不可读。
2. 拆解字段由当前书方案驱动，页面不能写死固定字段。
3. 页面只管理交互状态，核心保存逻辑交给后端或本地数据服务。
4. 不在顶部分页展示章节标题。
5. 不在正文下方常驻拆解表单。
6. 详细规则见 `docs/dev-guides/reading-workbench/`。

### 拆解卡片页

职责：

1. 展示当前书全部拆解卡片。
2. 支持按章节、拆解类型、标签、关键词、创建时间筛选。
3. 支持查看卡片详情、编辑字段、删除卡片。
4. 支持从拆解卡片跳转回原文位置。
5. 支持从拆解卡片创建或更新素材。

边界：

1. 拆解卡片属于具体书籍，不做跨书聚合。
2. 不把卡片退化成自由笔记，核心字段仍由拆解方案决定。

### 素材库页

职责：

1. 展示当前书中沉淀出的素材。
2. 支持按分类、标签、来源章节、关键词、收藏状态筛选。
3. 支持查看素材正文、编辑素材标题和说明。
4. 支持查看素材来源，包括书籍、章节、原文片段位置和来源拆解卡片。
5. 支持从素材跳转回原文或拆解卡片。
6. 支持删除、收藏、调整分类和标签。

边界：

1. 第一阶段素材库以当前书为边界，不主动扩张到跨书知识库。
2. 素材必须保留来源引用，不能只保存一段脱离上下文的文本。

### 拆解方案页

职责：

1. 管理当前书的拆解维度。
2. 管理拆解类型。
3. 管理字段名称、字段类型、顺序、必填、默认值、显示状态。
4. 支持从内置模板创建当前书方案。
5. 支持将当前书方案另存为模板。
6. 在修改字段前提示对既有拆解卡片的影响。

边界：

1. 每本书拥有独立方案，不能将字段写成全局固定模板。
2. 第一阶段不做多人协作、权限、复杂版本管理。
3. 删除或变更字段时必须考虑旧卡片数据的保留和迁移提示。

### 基础分析页

职责：

1. 按拆解类型统计数量。
2. 按标签统计数量。
3. 按章节展示拆解分布。
4. 展示基础进度，如已拆解章节数、素材数量、最近拆解时间。

边界：

1. 不做跨书比较。
2. 不做复杂人物关系图、剧情结构图或高级可视化。
3. 不让分析页成为第一阶段的主要工作流入口。

### 全局设置页

职责：

1. 管理主题、字号、窗口偏好、最近项目展示数量等应用级设置。
2. 管理应用级快捷键偏好。
3. 展示数据存储原则说明和缓存清理入口。

边界：

1. 不保存某一本书的正式业务数据。
2. 不在全局设置中管理某一本书的拆解字段、标签和分类。

| 组件 | 使用页面 | 职责 |

| `ProjectStatusBar` | 应用壳层、当前书工作区 | 展示当前项目、保存状态、最近操作反馈 |
| `BookProjectList` | 书库页 | 展示本地小说项目列表 |
| `ImportPreviewPanel` | 书库页 | 展示小说信息、导入信息和分页章节标题 |
| `ChapterCatalogButton` | 阅读工作台 | 打开右侧目录弹层 |
| `ChapterCatalogOverlay` | 阅读工作台 | 分页展示章节目录并默认定位当前章节所在页 |
| `ReaderPager` | 阅读工作台 | 承载上一页、下一页操作和翻页状态 |
| `ReaderPane` | 阅读工作台 | 展示正文、处理选择文本和阅读定位 |
| `SelectionToolbar` | 阅读工作台 | 提供选文后的快捷动作 |

## 状态与数据边界

页面状态建议按以下层级拆分：

1. 应用级状态：主题、窗口偏好、最近项目、当前打开项目路径。
2. 当前书状态：书籍元数据、章节目录、当前章节、阅读位置、拆解方案、标签分类。
3. 页面交互状态：筛选条件、当前选中文本、抽屉展开状态、表单草稿、加载与错误提示。

核心规则：

1. 应用级状态可以保存到应用系统数据目录。
2. 当前书正式数据必须保存到用户选择的小说项目目录。
3. 页面交互状态默认只存在于前端，必要时才持久化。
4. SQLite 只作为打开项目后的索引缓存，页面不能依赖它作为唯一数据源。

## 第一阶段优先级

建议按以下顺序推进页面编码：

1. 书库页：能设置书库目录、读取 `index.json`、打开小说、创建导入入口。
2. 书库内导入面板：能导入 TXT、编辑小说名和简介、分页查看章节标题、确认入库。
3. 阅读工作台：能恢复上次位置、读章节、上下翻页、选中文字、用弹框创建拆解卡片。
4. 拆解方案页：能调整当前书的拆解类型和字段。
5. 素材库页：能从拆解沉淀素材并回溯来源。
6. 拆解卡片页：能集中管理已有拆解。
7. 基础分析页：只做轻量统计。
8. 全局设置页：补齐应用级偏好。

前三项构成最小可用闭环，应优先完成。

## 编码前确认清单

进入页面编码前需要确认：

1. 是否采用上述顶层导航模型。
2. 阅读工作台是否已按阅读 / 编辑两个 TAB 实现。
3. 拆解卡片页是否在第一阶段独立出现，还是先只保留创建拆解弹框和保存能力。
4. 素材库第一阶段是否只展示当前书素材。
5. 默认拆解方案需要包含哪些维度、类型和字段。
6. 导入流程是否先只支持 TXT。
7. 是否需要在第一阶段支持正文编辑后的章节重新保存。
