# 全局素材库指南

本文定义全局素材库的职责和边界。全局素材库是应用级入口，只保存跨书引用索引和必要展示快照；小说内素材的正式数据仍保存在各自小说项目目录中。

## 目的

全局素材库用于跨书检索用户已经沉淀的素材。

它回答的问题是：

```text
我从所有小说项目中积累了哪些可复用写作素材
```

全局素材库不直接替代小说内素材模块。小说内素材模块规则见 `docs/dev-guides/book-material-library/implementation.md`。

## 页面职责

全局素材库属于应用级页面，不依赖当前是否打开某一本书。

页面职责：

1. 聚合展示所有已索引小说项目中的素材。
2. 支持按书籍、素材类型、分类、标签和关键词筛选。
3. 支持打开来源小说项目。
4. 支持跳转到小说内素材详情。
5. 当来源项目不存在或路径失效时，展示素材快照，并提示来源不可用。
6. 提供刷新索引能力，从已记录小说项目重新扫描小说内素材。

全局素材库不负责：

1. 不把素材正式正文只保存在全局索引。
2. 不要求用户导出数据库才能迁移单本小说素材。
3. 不自动跨书合并相似素材。

## 全局素材索引结构

全局素材索引保存在应用系统数据目录，不保存在某一本小说项目目录中。

示例：

```json
{
  "version": 1,
  "items": [
    {
      "bookId": "book-20260824-001",
      "bookPath": "D:/library/books/book-20260824-001",
      "materialId": "material-20260824-0001",
      "materialType": "storyPlot",
      "snapshot": {
        "title": "装逼打脸桥段的四段式推进",
        "summary": "压制、反差、爆发、围观确认共同放大爽点。",
        "bookName": "某本小说",
        "tagNames": ["装逼打脸", "围观反应"]
      },
      "indexedAt": "2026-08-24T10:35:00+08:00"
    }
  ]
}
```

原则：

1. 全局索引只保存引用和必要展示快照。
2. 打开素材详情时，优先读取 `bookPath` 指向的小说内素材正式数据。
3. 如果 `bookPath` 不存在，展示索引快照并提示来源项目不可用。
4. 全局索引损坏或删除后，必须能从已记录小说项目中的 `materials/materials.json` 重建。
5. 如果用户移动了小说项目目录，应允许重新定位项目并刷新索引。

## 来源状态

全局素材库应区分来源状态：

1. 来源可用：`bookPath` 存在，可以读取小说内素材详情。
2. 来源缺失：`bookPath` 不存在，只展示索引快照。
3. 来源损坏：项目目录存在，但 `materials/materials.json` 无法读取，应提示修复或重新扫描。
4. 索引过期：索引快照与小说内素材更新时间不一致，应提示刷新。

## 边界

第一阶段不做：

1. 自动跨书合并相似素材。
2. AI 自动整理素材。
3. 云同步或账号系统。
4. 多人协作素材库。
5. 复杂跨书比较和可视化。
